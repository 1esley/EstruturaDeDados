### Atividades
- [x] Atividade 1: Implementação de uma matriz simples e suas operações.
- [x] Atividade 2: Implementação de structs para organizar funcionários em uma lista vetor e manipulação de arquivos csv.
- [x] Atividade 3: Implementação de ponteiros e alocação de memória na atividade 2.
